# French — UI / UX

vous vs tu: same consistency rule as German Sie/du.

## Must

- Preserve accents in all UI (é, è, à, ç, …) — never strip for 'simplicity'
- Narrow no-break space before ; ! ? : and French quotation spacing per locale typography
- Plan for longer strings than English; gender-aware labels where the DESIGN requires them
- Pick fr-FR vs fr-CA for vocabulary (e.g. courriel vs e-mail) and document it

## Avoid

- ASCII-fied French (cafe without accent) in user-facing copy
- US date formats in fr locale screens

## Review prompts

1. Does the first viewport read correctly in LTR?
2. Is address/tone (formal vs informal) consistent?
3. Do strings fit without clipping after translation expansion?
