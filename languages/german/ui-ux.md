# German — UI / UX

Legal/consumer text may require German in DACH markets — product COMPLIANCE owns that.

## Must

- Decide Sie vs du (formal vs informal) once per product surface and keep it consistent
- Allow generous UI width — German strings often expand 20–40% vs English
- Capitalize nouns in UI copy correctly; do not 'simplify' by lowercasing nouns
- Use German typographic quotes and decimal comma in number examples when locale is de

## Avoid

- Mixing Sie and du in the same flow
- Truncating compounds with ellipsis that destroy meaning

## Review prompts

1. Does the first viewport read correctly in LTR?
2. Is address/tone (formal vs informal) consistent?
3. Do strings fit without clipping after translation expansion?
