# English — pitfalls

## Common failures

- Hardcoding en-US formats in a product whose market is en-GB or mixed
- Using English as the only stored content while claiming bilingual
- Putting non-English kit instructions 'for authenticity' (forbidden — SF-21)

## Confused with

| Other | Note |
|-------|------|
| Kit documentation language (always English) | See selector |
| Product UI English locale | See selector |

## Combines with

- arabic (bilingual MENA products)
- other locale packs when adding languages

## Checklist before Done

1. `lang` / `dir` correct on document?
2. Catalogs cover this locale for user-facing strings?
3. Collation/search policy documented?
4. No kit docs written *in* this language (instructions stay English — SF-21)?
5. Formality and regional variant chosen?
