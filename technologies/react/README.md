## When to open this pack

- Writing **React** UI (components, hooks, client interactivity) — including under Next.js, Vite, Inertia React, or React Native renderers.
- Choosing modern React 19 APIs vs legacy class / React 17–18 patterns.
- Avoiding Create React App and removed React 19 APIs in new code.
