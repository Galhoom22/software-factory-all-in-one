# Shared documents — reading order

Product repos keep **flat** filenames under `docs/` (compatible with CI and AGENTS). Use this numbered order when filling or reviewing them.

| Order | File | Purpose |
|------:|------|---------|
| 00 | [`AGENT_START.md`](AGENT_START.md) | Short onboarding for any / weak model |
| 01 | [`BRD.md`](BRD.md) | Why (business) |
| 02 | [`PRD.md`](PRD.md) | What (features) |
| 03 | [`SRS.md`](SRS.md) | How (stack, FR/NFR, owners) |
| 04 | [`API_CONTRACT.md`](API_CONTRACT.md) | Shared FE/BE interface |
| 05 | [`COMPLIANCE.md`](COMPLIANCE.md) · [`SECURITY.md`](SECURITY.md) | Red lines |
| 06 | [`DELIVERY.md`](DELIVERY.md) | Actor-loop delivery |
| 07 | [`DECISIONS.md`](DECISIONS.md) · [`decision-logs/`](decision-logs/) | Lasting + light forks |
| 08 | [`REFERENCES.md`](REFERENCES.md) | External borrows (taken / rejected) |
| 09 | [`SCOPE_REJECTIONS.md`](SCOPE_REJECTIONS.md) | Stable `REJ-xx` bans |
| 10 | [`JUDGMENT.md`](JUDGMENT.md) | Outside methods mapped in |
| 11 | [`actors/`](actors/) | Per-actor `screens.md` / `flow.md` |
| 12 | [`learning-from-mistakes/`](learning-from-mistakes/) | Engineering aha notes |
| 13 | frontend/ · backend/ | Owner-split guides |
| 14 | SEO · DOCKER · DEPLOYMENT · AI · review tools | As needed |

Prototype craft files live under `project-ui/` (`PRE-DELIVERY-UX.md`, `ANTI-SLOP.md`, `DESIGN-ERRORS.md`).
