# Decision logs (light forks)

Use this folder for **expensive but not ADR-level** choices: urge, contrarian, precedent, pick, reject.

Lasting architecture and product decisions still go in [`../DECISIONS.md`](../DECISIONS.md) (never edit an accepted entry — supersede it).

## Naming

`YYYY-MM-DD-short-kebab-topic.md`

## Template

```markdown
# YYYY-MM-DD — <topic>

**Status:** accepted | rejected | superseded by D-xx / ADR-xxx

## Urge

First plausible answer.

## Contrarian

A real alternative (invert the urge).

## Precedent

What this repo / ADRs / official docs already say.

## Choice

What we picked.

## Rejected

What we did not pick, and why.
```
