# Delivery Method — Actor Loop

**Status:** Mandatory.  
**Audience:** every human and AI agent in this planning repository.

Copy and adapt from the playbook’s [`02-DELIVERY.md`](../../02-DELIVERY.md). Keep the hard rules below.

## 1. There is no MVP delivery mode

Do not build “an MVP first, then the real product.” Do not omit, stub, or weaken screens, copy, pricing, or rules for the **actor in focus**.

## 2. The only loop

1. **Plan here** — pick the next actor.
2. **Discuss** — settle business and product rules for that actor.
3. **Design production-ready** — every screen, state, and rule at the same bar as production (millimetre-accurate). **Production bar:** millimetre-accurate to what ships.
4. **Implement elsewhere** — backend and frontend finish that actor.
5. **Return here** — open the next actor and repeat.

## 3. Production bar

If a prototype screen would not ship as drawn, fix it here before implementation.

## 4. Sequencing vs incompleteness

Deferred lists and other actors wait their turn. That never means the current actor ships incomplete.
